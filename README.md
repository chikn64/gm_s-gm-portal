# GM Portal

A small game portal with a few browser-based mini-games.

## Features
- Tic-Tac-Toe
- Memory Match
- Reaction Test
- Static front-end with no build step required

## Run locally
Open `index.html` directly in a browser, or run a small local server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000` in your browser.

## Project structure
- `index.html` — landing page
- `styles.css` — styling
- `script.js` — game logic

## Notes
This project is intentionally lightweight so it can work in a browser without external dependencies.
